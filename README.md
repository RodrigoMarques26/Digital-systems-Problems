**Digital Systems Problems**

This repository contains practical exercises and projects developed during the Digital Systems course, using VHDL and FPGA hardware.
The main goal is to practice digital logic design, understand hardware description using VHDL, and explore different implementation techniques.

***Tools and Technologies***

VHDL: Hardware Description Language used to develop the digital circuits.
Intel Quartus II: Used for code compilation, synthesis, and FPGA programming.
Visual Studio Code: Used to edit, organize, and document the source code.

***Hardware***

The exercises use two interconnected development boards:
**DE0-Nano FPGA Board**

Main development board containing the FPGA.
Onboard LEDs used to display binary results.
Provides the hardware platform for running the VHDL projects.

**UFPE/DES Didactic Expansion Board**

Custom expansion board developed by the course instructors.
Provides physical switches and push-buttons for circuit inputs.
Includes a 7-segment display for displaying numerical values and status indicators.
